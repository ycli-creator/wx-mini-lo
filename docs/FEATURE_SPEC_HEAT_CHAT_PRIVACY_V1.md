# Love Points 热力、聊天与空间隐私实施规格 V1

> 确认日期：2026-08-30

## 产品模式

- 未绑定时是单人空间：任务、积分、奖励、私密记录和个人文档仅本人使用。
- 绑定后创建新的情侣空间：共同积分、热力、聊天、共同任务、共同文档和伴侣共享记录均归属于该 `coupleId`。
- 单人空间积分不迁入情侣空间；情侣空间积分也不迁回单人空间或下一段关系。新情侣空间可按产品初始规则获得独立起始余额。
- 双方确认解绑后，情侣空间及其积分、热力、聊天、共同内容和访问令牌全部清空。

## 隐私规则

- 私密是默认值；绑定不会自动公开绑定前或绑定后的个人内容。
- 情绪、事件可由本人选择 `self` 或 `couple`；经期不允许公开。
- 共同文档、任务、积分、热力和聊天只允许当前情侣双方访问。
- 社区帖子只有明确发布且伴侣确认后才公开。
- 服务端每次读取或操作均从 OpenID 校验当前 `coupleId` 成员关系；客户端不直写业务集合。

## 导航

底部导航调整为：首页、任务、社区、聊天、我的。共享文档保留为首页与个人页中的二级入口。

## V1 范围

- 情侣共享总热力、今日热力、热力流水和每日五项任务。
- 四项固定任务与一项稳定随机任务；随机结果由 `coupleId + Asia/Shanghai 日期` 决定。
- `0/2` 双人进度、个人奖励和只发一次的 Pair Bonus。
- 情侣聊天：文本、业务卡片、未读红点、发送失败状态和刷新。
- `@TA`：发送到情侣聊天；单纯点击不增加热力，对方打开卡片后才完成互动任务。
- 微信分享：热力任务、公开社区帖子和绑定邀请；私密内容不直接外发。
- 不做 WebSocket、语音、视频、撤回、消息搜索或 UI 已读回执。

## 空间生命周期

1. 新用户自动拥有单人空间语义，但不显示情侣能力。
2. 绑定成功创建全新的情侣空间及独立账户。
3. 解绑申请期间情侣空间仍可用。
4. 双方确认后删除所有 `coupleId` 子数据，再解除双方关系。
5. 用户回到新的单人空间；之后再次绑定时创建全新的情侣空间。
