# Love Points 部署与双人验收清单

代码和本机自动化验证已经完成。以下步骤需要登录你的微信开发者账号后操作；AppSecret、CloudBase 密钥和上传私钥不需要提供给本项目，也不要发到聊天中。

截至 2026-09-02，体验版 `0.3.0` 已上传。当前仓库已扩展为 28 个集合、52 个自定义索引；社区治理改动尚未部署，云端仍是上一版结构。本次未提交审核、未正式发布。

## 1. 微信开发者工具

1. 打开微信开发者工具并登录。
2. 进入“设置 → 安全设置”，开启“服务端口”。
3. 导入仓库根目录 `lapp`，不要只导入 `miniprogram` 子目录。
4. 确认 `project.config.json` 使用当前个人小程序 AppID `wx2f2b626c271ccbcc`。
5. 选择“工具 → 构建 npm”，确认生成 `miniprogram_npm/tdesign-miniprogram`。

AppID 可以写入项目；AppSecret 不可以写入项目。

## 2. CloudBase 云开发

1. 在开发者工具中开通一个云开发环境。
2. 参照 `cloudfunctions/database-schema.json` 创建 28 个集合与 52 个自定义索引。
3. 将所有业务集合权限统一设为“仅管理端可读写/无客户端权限”；客户端只调用云函数。
4. 右键 `cloudfunctions/api`，安装依赖并上传部署，云端安装依赖。
5. 在云函数配置中确认超时时间为 20 秒、内存保持免费档默认的 256 MB。
6. 将环境 ID 填入 `miniprogram/config/env.ts` 的 `CLOUD_ENV_ID`。
7. 在仓库根目录执行 `npm run verify:deployment-config`，确认两个占位配置都已替换。

## 3. 开发者工具验收

- 启动页、邀请、首页、任务、积分、奖励、文档、设置和解绑页面均无编译错误。
- 首次资料、个人页、社区发布/确认、生活日历和经期隐私选项均无编译错误。
- 控制台没有云函数不存在、环境 ID 无效、集合不存在或权限配置错误。
- 在常用模拟器尺寸检查底部安全区、长标题换行、输入框和弹窗。

## 4. 两名微信用户真机验收

1. A 创建邀请，B 输入 6 位短码，A 同意绑定。
2. B 提交任务，A 审批；连续点击审批不会重复加分。
3. 创建奖励并兑换；余额不足时禁止兑换，重复点击不会重复扣分。
4. 发起退款，对方通过后只返还一次积分。
5. A 编辑文档时，B 只能只读；A 保存或离开后 B 可以获得编辑锁。
6. A 发起解绑时数据仍保留；B 同意后情侣空间数据清空，双方可以重新绑定。
7. A 发布一条纯文字帖子；B 确认前第三方看不到，B 同意后公开社区可见；图片或视频应被客户端和服务端明确阻止。
8. A 新建一条仅自己可见的经期记录，B 不可见；A 新建双方可见事件后，B 可在同一天看到。
9. 新建“双方每天各自完成”的待办，A、B 分别完成后双方进度颜色正确，积分分别到账，且只有双方完成后任务才结束。
10. 双方分别编辑同一待办并添加照片，详情页能查看修改、完成和照片记录；大任务每一步均可添加照片。
11. 发布人编辑帖子时标题与正文分别回填和保存；公开帖子修改后重新进入伴侣确认。

## 5. 发布前安全复查

- 执行根目录 `npm run verify`。
- 重新检查 `wx-server-sdk` 是否已有修复传递依赖告警的新版本，详见 `docs/SECURITY_NOTES.md`。
- 不上传任何 AppSecret、云密钥或 CI 私钥。
- 在云函数配置中保留 `security.msgSecCheck` 云调用权限；当前社区已安全降级为纯文字，并已加入应用内协议、举报、撤回和删除。正式提审前仍需在微信公众平台配置完整隐私保护指引；恢复社区图片/视频前必须接通对应媒体审核能力。
- 个人自用也建议先以“体验版”完成两台真机验收，再提交正式版本。
- 本次只生成体验版，不提交审核、不正式发布。
