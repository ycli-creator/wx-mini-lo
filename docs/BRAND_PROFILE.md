# 爱心点数｜品牌与应用资料

## 推荐名称

- 中文名称：**爱心点数**
- 英文名称：**Love Points**
- 一句话定位：情侣共同生活的任务、积分与记录空间。

> 微信平台中的名称能否使用，以提交时的名称查重和审核结果为准。

### 备用名称

1. 两个人的点数
2. 心意搭档
3. 双人小日常

## 应用简介

### 平台短简介

情侣专属的任务、积分、社区与生活记录空间。

### 完整介绍

爱心点数是一款为情侣打造的双人互动小程序。双方可以一起完成任务、积累个人与共同积分、兑换奖励，也可以通过情侣社区、生活日历和共享文档记录日常，把想一起完成的事和值得纪念的瞬间留在同一个空间。

### 宣传语

**把想一起完成的事，一件件变成爱心点数。**

### 分享文案

和喜欢的人一起定任务、攒积分、换奖励，也把每天的小事认真记录下来。

## 产品关键词

- 情侣任务
- 双人积分
- 奖励商店
- 情侣社区
- 生活日历
- 共同记录

## 核心功能概述

1. **情侣绑定**：通过邀请卡片或短码建立双方专属空间。
2. **任务与审批**：创建个人或共同任务，由伴侣完成或确认，并获得积分。
3. **积分与奖励**：管理个人及共同积分，在任务页内创建、兑换双方约定的奖励。
4. **情侣社区**：发布文字、照片或视频；帖子经双方确认后才进入公开社区。
5. **生活日历**：按日期记录情绪、事件和经期信息，并可设置个人或双方可见。
6. **个人资料**：维护用户名、性别、地区和爱好等信息，并在个人页集中查看。
7. **共享文档**：共同整理计划、清单与重要记录。
