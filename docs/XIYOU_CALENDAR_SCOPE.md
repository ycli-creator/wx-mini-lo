## 页面范围

升级现有生活日历入口。核心交互是：选择某天，下方原地显示并编辑这一天的记录。截图用于确定布局和可见行为，APK 用于核对具体记录选项与状态转换。

| 区域 | 纳入内容 | 证据或约束 |
|---|---|---|
| 顶部状态 | 下一次经期预计倒计时；无足够数据时提供设置/补录入口 | 原版无模型时可回退日期文字；补录入口是本项目设计。倒计时必须动态计算 |
| 月历 | 月份切换、选择日期、今天标记、返回今天 | 截图可见日期网格；月份导航采用本项目可用方式 |
| 周期标记 | 实际月经期、预测经期、预计易孕期、预计排卵日及图例 | 四类图例在截图可见；预测应与已记录数据区别显示 |
| 经期行 | 所选日期的开始/结束操作、历史修正；经期内流量和痛经 | 起止为区间状态机；流量、痛经均五档，可取消；暂定结束与确认结束分开 |
| 亲密行 | 点击加号打开记录面板、保存后可查看/修改/删除 | 每条含时间和四选一措施；每天最多 20 条 |
| 心情行 | 点击表情快捷记录、切日期回显、纠正误操作 | 五项各自累计、每项每日最多 99 次；长按完整手势需运行核验 |
| 好习惯行 | 图标快捷打卡、切日期回显、纠正误操作 | 吃早饭、吃水果、多喝水、运动、排便；五个独立布尔打卡，重复点击取消 |

页面布局遵循截图的上下结构，颜色、文字与组件适配现有小程序。日记录面板常驻月历下方，替代“点日期先弹整屏抽屉”的主路径。

## 必要支撑

- 记录可持久保存、回显和修正；同步更新小程序服务层、本机模式与云函数。
- 最小周期设置支撑页面内预测；已定位客户端公式、智能周期与配置覆盖，尚未核对设备实际参数，不宣称逐日结果完全一致。
- 健康记录默认私密，个人持有与情侣可见权限分开，避免解绑后个人健康历史不可访问。
- 修正现有先取 500 条再筛月份的问题；按日期范围查询并处理分页。
- 旧版单日经期条目保留，不自动推断不存在的完整周期。
- 日期统一口径，验证跨月、闰日、补记、更正、重复提交与权限。
