# Love Points 微信小程序

这是从现有 Figma 与 React Web 原型迁移出的微信原生 TypeScript 小程序工程。

## 当前已完成

- 23 个页面：在 V1 闭环上新增首次资料、个人页、社区发布和生活日历。
- 首页、任务、社区、文档、我的五项自定义底部导航；奖励商店已整合进任务页。
- 邀请/绑定、个人资料、任务提交/审批、个人与共同积分、奖励创建/兑换/退款、社区共同确认发布、生活记录、文档保存与双向解绑的本机体验闭环。
- 二级页面统一返回入口；生活日历在日期下显示情绪，详细记录点击日期后再打开。
- 任务支持每日、每周、长期计划；每日和每周按上海时区自动生成新周期，跨周期待审批记录不会丢失。
- TDesign 基础按钮封装，以及按 Figma 映射的颜色、字号、间距、圆角和卡片样式。
- 统一服务层：`config/env.ts` 未配置环境 ID 时使用本机数据；配置并部署 CloudBase 后使用同一套页面进行真实双人同步。

## 本地检查

```bash
npm install
npm run verify
```

## 在微信开发者工具中打开

1. 安装微信开发者工具。
2. 登录后在“设置 → 安全设置”中开启“服务端口”。
3. 导入仓库根目录 `lapp`，工具会读取根目录的 `project.config.json`。
4. 在“工具 → 构建 npm”中生成 `miniprogram_npm`。
5. 当前 `project.config.json` 已配置个人小程序 AppID `wx2f2b626c271ccbcc`；不要把 AppSecret 写入工程。

完整的云环境部署和双人验收步骤见 `docs/DEPLOYMENT_CHECKLIST.md`。

## CloudBase 接入边界

`cloudfunctions/api` 已实现微信 OpenID、情侣空间隔离、周期计划、服务端事务、不可变积分流水、奖励退款、文档编辑锁与双向解绑。数据集合与云函数部署完成前，保持 `config/env.ts` 中的 `CLOUD_ENV_ID` 为空即可使用本机体验数据。
