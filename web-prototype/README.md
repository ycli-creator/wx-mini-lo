# Love Points 本地交互原型

这是微信小程序接入前的本地 Web 原型，用于先验证完整 UI 和核心业务流程。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4173`。

## 当前范围

- 覆盖 Figma 中的 16 个页面，并补充一个任务主页面。
- 主应用使用“首页 / 任务 / 奖励 / 文档 / 我的”五项底部导航；二级流程页面保持专注，不显示 Tab。
- 支持邀请与绑定模拟、任务提交/审批、个人与共同积分、奖励创建/兑换/退款、共享文档保存、双向解绑。
- 数据仅存储在浏览器 `localStorage`，刷新后保留。
- 桌面浏览器左侧提供 16 页原型目录；手机宽度下只显示产品界面。
- 微信登录、分享、云数据库、云函数和真实多人同步尚未接入。
